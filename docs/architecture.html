Factory Inventory Management System

A full-stack demo application: a Vue 3 single-page app talking to a FastAPI service that serves in-memory data loaded from JSON files. No database.

Three tiers, two processes. Everything runs locally; the browser is the only client.

Data flow

How a filter change on the dashboard becomes updated numbers on screen.

  1. User changes a filterPeriod, warehouse, category or order status in the filter bar.
  2. Shared filter state updatesuseFilters holds four singleton refs, so every view sees the same selection.
  3. View requests datagetCurrentFilters() is passed to api.js, which drops any filter set to all and builds the query string.
  4. FastAPI filters in memoryapply_filters and filter_by_month run over the lists loaded from JSON. Month accepts 2025-01 or quarters like Q1-2025.
  5. Response is validatedPydantic response_models shape the JSON; the dashboard summary aggregates totals server-side.
  6. View rendersRaw results sit in refs; derived values are computed properties that drive the charts and tables.

Things to know

Observed while reading the code.

Frontend calls endpoints the backend does not define. api.js includes /api/tasks (GET, POST, PATCH, DELETE) and /api/purchase-orders (POST, GET by backlog item), but server/main.py has no matching routes. Purchase orders are only read from purchase_orders.json to set has_purchase_order on backlog items. Those calls will return 404 until the routes are added.
